# Flash 分区表

## 内部 Flash（256KB）

```
0x08000000  ┌──────────────────────┐
            │  Bootloader  16KB    │  上电就跑这里
0x08004000  ├──────────────────────┤
            │  App-A       96KB    │  槽 A
0x0801C000  ├──────────────────────┤
            │  App-B       96KB    │  槽 B
0x08034000  ├──────────────────────┤
            │  元数据       4KB    │  活动槽 / 试启动 / CRC
0x08035000  ├──────────────────────┤
            │  预留        44KB    │
0x08040000  └──────────────────────┘
```

## 关键地址宏（两边的代码必须一致）

| 宏 | 值 | 含义 |
|---|---|---|
| `OTA_BOOT_ADDR` | `0x08000000` | Bootloader 起始 |
| `OTA_SLOT_A_ADDR` | `0x08004000` | App-A 起始 |
| `OTA_SLOT_B_ADDR` | `0x0801C000` | App-B 起始 |
| `OTA_SLOT_SIZE` | `0x18000` | 每个槽 96KB |
| `OTA_META_ADDR` | `0x08034000` | 元数据页 |

## 为什么是 96KB

App 编译后如果小于 96KB，两槽 + Bootloader + 元数据 = 16 + 96 + 96 + 4 = 212KB，塞得进 256KB。

**如果 App 超过 96KB，必须调整这个表**，改完两边代码的宏要同步。

## W25Q128（16MB，SPI）

| 地址 | 大小 | 用途 |
|---|---|---|
| `0x000000` | 64KB | 升级包暂存 |
| `0x010000` 起 | 剩余 | 开锁日志（循环写） |
